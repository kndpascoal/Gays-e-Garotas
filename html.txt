  COMO USAR ESTE ARQUIVO:

  1) Tudo que você precisa editar (nome do evento, datas, line-up,
     palcos, ingressos, redes sociais) está centralizado no objeto
     "CONFIG" dentro da tag <script> no final do arquivo.
     Edite só o CONFIG e o site inteiro se atualiza sozinho — não
     precisa mexer no HTML/CSS pra trocar texto ou artista.

  2) Cores, fontes e espaçamentos ficam nas variáveis CSS lá em
     cima (:root), logo abaixo deste comentário. Trocar uma cor ali
     muda o site inteiro de uma vez.

  3) IMAGENS E ÍCONES — onde colocar e em que formato:

     /img/logo.svg
        - Logo do evento. Prefira SVG (vetor, fica nítido em
          qualquer tamanho) com fundo TRANSPARENTE.
        - Se só tiver PNG, use PNG-24 transparente, altura ~120px.

     /img/hero-bg.jpg  (ou hero-bg.mp4 se quiser vídeo de fundo)
        - Imagem de fundo do topo do site (hero).
        - Tamanho recomendado: 1920x1080px (paisagem), JPG ou WEBP,
          otimizada (até ~400kb) pra não pesar o carregamento.

     /img/artistas/nome-do-artista.jpg
        - Foto de cada atração do line-up.
        - Formato quadrado 800x800px, JPG/WEBP, mesmo enquadramento
          pra todas (rosto centralizado) — mantém a grade alinhada.

     /img/palcos/nome-do-palco.jpg
        - Foto ou ilustração de cada palco/área.
        - Formato retangular 1200x800px, JPG/WEBP.

     /img/icons/*.svg
        - Ícones pequenos (instagram, localização, ingresso, etc).
        - Use SVG monocromático (aceita "currentColor" no fill pra
          herdar a cor do texto). Ícones gratuitos: lucide.dev,
          feathericons.com, heroicons.com — baixe em "outline" 24x24.
        - Este template já usa ícones inline (SVG direto no HTML)
          pra não depender de arquivos externos. Pra trocar um
          ícone, procure o comentário "ÍCONE:" e substitua o
          conteúdo do <svg>...</svg> por outro da mesma biblioteca.

     favicon.ico / favicon.png
        - Ícone da aba do navegador. 32x32 ou 64x64px.

  4) Este arquivo é 100% autocontido (HTML + CSS + JS num arquivo
     só) pra facilitar edição. Se o projeto crescer, dá pra separar
     em style.css e script.js sem problema.
====================================================================
-->

// --- Contador regressivo ---
function tickCountdown(){
  // Converte "18/08/2026 - 16:00:00" para o formato aceito pelo navegador
  const [data, hora] = CONFIG.dataInicio.split(' - ');
  const [dia, mes, ano] = data.split('/');
  
  const alvo = new Date(`${ano}-${mes}-${dia}T${hora}`).getTime();
  const agora = Date.now();
  const diff = Math.max(0, alvo - agora);

  const d = Math.floor(diff / 86400000);
  const h = Math.floor((diff % 86400000) / 3600000);
  const m = Math.floor((diff % 3600000) / 60000);
  const s = Math.floor((diff % 60000) / 1000);

  document.getElementById('cd-dias').textContent = String(d).padStart(2,'0');
  document.getElementById('cd-horas').textContent = String(h).padStart(2,'0');
  document.getElementById('cd-min').textContent = String(m).padStart(2,'0');
  document.getElementById('cd-seg').textContent = String(s).padStart(2,'0');
}
tickCountdown();
setInterval(tickCountdown, 1000);
